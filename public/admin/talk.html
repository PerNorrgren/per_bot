Talk knowledge
Signal scripts
Pre-written mini-practices — most under a minute, plus a longer five-minute set for when Talk offers someone the choice — Talk can weave into a live conversation when genuinely relevant, either spoken text, or an existing library audio file. Talk only ever sees the topic and situation for each one, never the full text — so this list can grow freely without making every conversation more expensive. Leave skin blank for "every skin, including standard" — set one to scope it to just that skin (e.g. Mare).

Pacing note for text scripts: unlike live conversation, these get synthesized as one continuous audio clip — [[PAUSE]] does nothing here and will just be stripped. Build the pacing into the words themselves instead — a counted breath ("in for four, out for six"), a slow count to five — so there's something to actually do while the narration keeps gently going, rather than relying on silence that this pathway can't produce.
