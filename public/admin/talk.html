Signal scripts
Short, pre-written mini-practices (under a minute) Talk can weave into a live conversation when genuinely relevant — either spoken text, or an existing library audio file. Talk only ever sees the topic and situation for each one, never the full text — so this list can grow freely without making every conversation more expensive.
